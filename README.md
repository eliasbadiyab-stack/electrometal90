# Electro Metal – پلتفرم جامع مهندسی الکترونیک و فروشگاه اختصاصی

**سازنده و بنیان‌گذار:** الیاس بادیاب (Elias Badiyab)  
**ایمیل مالک:** `eliasbadiyab@gmail.com`  
**برند پیش‌فرض:** Electro Metal (الکترو متال)  
**حوزه فعالیت پیش‌فرض:** مهندسی الکترونیک، طراحی بردهای مدار چاپی (PCB)، شبیه‌سازی‌های Proteus و Altium، فروش فایلهای دیجیتال و قطعات فیزیکی.

---

## ۱. ویژگی‌ها و ماژول‌های پیاده‌سازی شده

### ۱.۱. پنل مدیریت مالک و CMS بدون نیاز به کدنویسی
- **هویت برند و محتوای سایت:** امکان تغییر آنی نام برند، نام سازنده (الیاس بادیاب)، عنوان سئو، توضیحات متا، تلفن، آدرس دفتر، ایمیل، لوگو و فوتر.
- **تغییر شبکه‌های اجتماعی:** تنظیم لینک کانال یوتیوب، کانال تلگرام، اینستاگرام، گیت‌هاب و لینکدین.
- **مدیریت تم و رنگ‌بندی:** پشتیبانی کامل از Dark Mode و Light Mode به همراه رنگ‌های پایه صنعتی.
- **فعال/غیرفعال کردن امکانات:** خاموش یا روشن کردن پیام‌رسان داخلی، سیستم تیکت، ثبت‌نام کاربران، فروش فایل دیجیتال، تبلیغات و اخبار.

### ۱.۲. سازنده صفحه اصلی پویا (Page Builder)
- افزودن بخش‌های جدید به صورت ماژولار: الکترونیک، فایل‌های دانلودی، قطعات فیزیکی، کتابخانه مهندسی، بیت و موسیقی، اخبار و ویدیوها.
- تعیین ترتیب نمایش (Move Up / Down)، پنهان‌سازی موقت یا حذف بخش‌ها بدون نیاز به ویرایش سورس کد.

### ۱.۳. فروشگاه دیجیتال و فیزیکی
- **پشتیبانی کامل از فایل‌های دیجیتال:** ZIP, RAR, 7Z, PDF, HEX, BIN, INO, GERBER, PRJ, PDS, MP3, WAV و غیره.
- **امنیت فایل‌های دانلودی:**
  - فایل‌ها قبل از پرداخت مستقیم قابل دانلود نیستند.
  - پس از پرداخت موفق درگاه بانکی، توکن امن رمزنگاری شده منحصربه‌فرد (Secure Token) با مهلت زمانی و سقف دانلود مشخص صادر می‌شود.
  - قابلیت ابطال توکن یا تمدید سقف دانلود از پنل مدیریت توسط مالک.
- **محصولات فیزیکی:** مدیریت انبار، ابعاد، وزن، کدهای رهگیری پستی و آدرس گیرنده.

### ۱.۴. معماری پرداخت واقعی شاپرک و زرین‌پال
- سبد خرید تعاملی (Cart Drawer) با قابلیت تغییر تعداد و تفکیک کالای دیجیتال و فیزیکی.
- تسویه‌حساب (Checkout) با دریافت اطلاعات مشتری و آدرس پستی.
- شبیه‌ساز امن درگاه پرداخت الکترونیک شاپرک:
  - فرم استاندارد ۱۶ رقمی کارت بانکی، CVV2، تاریخ انقضا و درخواست رمز پویا (OTP).
  - صدور شماره مرجع تراکنش (RRN)، کد پیگیری بانکی و اعتبارسنجی تراکنش.
  - ارائه دسترسی آنی به فایل‌های دانلودی در صفحه موفقیت پرداخت.

### ۱.۵. مدیریت کاربران، اعضای ویژه و تیک آبی (Verification Badge)
- سطوح دسترسی (RBAC): مالک (Owner)، مدیر سیستم (Admin)، مدیر محصولات (Product Manager)، پشتیبانی (Support)، ویرایشگر (Editor) و کاربر عادی (User).
- **سیستم تیک آبی:** قابلیت فعال/غیرفعال‌سازی تیک آبی تایید شده برای هر کاربر یا حساب خود مالک با نشان رسمی.
- **نمایش اعضای ویژه و همکاران:** انتخاب کاربران خاص جهت نمایش در بخش تیم مهندسی صفحه اصلی.
- مسدودسازی (Block) و فعال‌سازی مجدد حساب‌ها.

### ۱.۶. پیام‌رسان داخلی و تیکت‌های پشتیبانی
- گفتگوی مستقیم بین کاربران و پرسنل با قابلیت ضمیمه کردن فایل‌های مدار و شماتیک.
- سیستم تیکتینگ کامل با اولویت‌بندی (عادی، فوری، بحرانی) و دپارتمان‌های فنی، مالی و دانلود.
- کنترل سراسری پیام‌رسان از پنل مدیریت مالک.

### ۱.۷. فایل منیجر، تبلیغات داخلی و اخبار یوتیوب
- مدیریت فایل‌ها در پوشه‌های تفکیک شده با قابلیت آپلود، تغییر نام و حذف.
- بنرهای تبلیغاتی با جایگاه‌های Homepage, Between-Products, Sidebar و رهگیری کلیک و نمایش.
- بخش اطلاعیه‌ها با لینک مستقیم ویدیوی جدید یوتیوب و کانال تلگرام.

### ۱.۸. امنیت، لاگ فعالیت (Audit Log) و پشتیبان‌گیری
- ثبت کلیه وقایع و تغییرات مهم مدیران در لاگ سیستم.
- دریافت فایل خروجی کامل دیتابیس در قالب استاندارد JSON و امکان بازگردانی (Restore) در هر زمان.
- بازنشانی به تنظیمات کارخانه (Factory Reset).

## ۲. راهنمای اجرا و استقرار (Production Deployment)

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای محیط توسعه
```bash
npm run dev
```

### بیلد نهایی برای پروداکشن
```bash
npm run build
```
خروجی بهینه‌سازی شده در دایرکتوری `dist/` قرار می‌گیرد.
